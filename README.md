# Ultrasonic-Radar-System
Arduino-based radar system that detects objects and their distance using an ultrasonic sensor, visualized in real-time on a PC.

Components Used
Arduino UNO
HC-SR04 Ultrasonic Sensor
Jumper Wires
Breadboard
USB Cable
Processing IDE (for radar display)
Features
Real-Time Distance Measurement
Live Radar-Style Visualization
Object Detection Alerts
Control Method

The ultrasonic sensor continuously measures distance to nearby objects. This data is sent via serial communication to a PC, where it's displayed as a radar-style visualization using Processing.
